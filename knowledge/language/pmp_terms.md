# PMP Terms（核心术语库）

> **用途**：PMP 考试核心英文术语的中英映射与应试释义。每条术语含考试含义、关键词、场景与易混概念。
>
> **调用**：Agent 讲解、Terminology Problem 错因分析、`question_analysis` 知识点标注。
>
> **关联**：`confusing_terms.md`、`keyword_mapping.md`、`synonym_mapping.md`

---

## 术语条目结构

每条术语统一字段：

| 字段 | 说明 |
|------|------|
| **English Term** | 英文原词 |
| **中文名称** | 推荐中文 |
| **PMP考试含义** | 应试视角一句话 |
| **关键词** | 题干信号词 |
| **常见场景** | 典型考题情境 |
| **易混淆概念** | 对比项 |
| **Example** | 短例句或考题片段 |

## 范围管理（Scope）

### Validate Scope（确认范围）

| 字段 | 内容 |
|------|------|
| **English Term** | Validate Scope |
| **中文名称** | 确认范围 |
| **PMP考试含义** | 正式验收可交付成果，获得客户或发起人对**范围**的签字认可 |
| **关键词** | Customer Acceptance, Deliverable, Formal Acceptance, Sign-off |
| **常见场景** | 阶段或项目交付物完成，问客户如何正式接受成果 |
| **易混淆概念** | Control Quality（检查可交付成果**质量**是否符合标准，非正式验收范围） |
| **Example** | *The customer formally accepts the deliverable after validation.* → Validate Scope |

### Control Scope（控制范围）

| 字段 | 内容 |
|------|------|
| **English Term** | Control Scope |
| **中文名称** | 控制范围 |
| **PMP考试含义** | 监督项目范围状态，管理基准变更，防止未批准的范围扩大 |
| **关键词** | Scope Creep, Baseline, Change Request, Variance |
| **常见场景** | 客户口头加需求、范围偏离 WBS |
| **易混淆概念** | Validate Scope；Perform Integrated Change Control |
| **Example** | *Unapproved features were added.* → Scope Creep，应 Control Scope + 变更流程 |

### Define Scope / Create WBS

| 字段 | 内容 |
|------|------|
| **English Term** | Create WBS |
| **中文名称** | 创建 WBS |
| **PMP考试含义** | 将可交付成果分解为更小、可管理的工作包 |
| **关键词** | Work Package, Decomposition, Deliverable |
| **常见场景** | Planning 阶段范围分解 |
| **易混淆概念** | Define Scope（范围说明书，先于 WBS） |
| **Example** | *Break down deliverables into work packages.* → Create WBS |

## 质量管理（Quality）

### Control Quality

| 字段 | 内容 |
|------|------|
| **English Term** | Control Quality |
| **中文名称** | 控制质量 |
| **PMP考试含义** | 监督并记录质量活动结果，判断可交付成果是否符合质量标准 |
| **关键词** | Inspection, Test, Defect, Quality Metrics |
| **常见场景** | 缺陷发现、测试失败、返工 |
| **易混淆概念** | Validate Scope；Manage Quality（质量保证，过程审计） |
| **Example** | *Inspect deliverables against quality standards.* → Control Quality |

### Manage Quality

| 字段 | 内容 |
|------|------|
| **English Term** | Manage Quality |
| **中文名称** | 管理质量 |
| **PMP考试含义** | 将质量政策转化为可执行的质量活动（质量保证、过程改进） |
| **关键词** | Quality Audit, Process Improvement, Quality Policy |
| **常见场景** | 过程是否符合计划、质量审计 |
| **易混淆概念** | Control Quality（针对可交付成果检查） |
| **Example** | *Audit whether processes follow the quality plan.* → Manage Quality |

## 风险与问题（Risk & Issue）

### Risk Register

| 字段 | 内容 |
|------|------|
| **English Term** | Risk Register |
| **中文名称** | 风险登记册 |
| **PMP考试含义** | 记录已识别风险、分析结果与应对计划 |

| **易混淆概念** | Issue Log |

### Issue Log

| 字段 | 内容 |
|------|------|
| **English Term** | Issue Log |
| **中文名称** | 问题日志 |
| **PMP考试含义** | 记录已发生、需处理的问题及责任人 |
| **关键词** | Occurred, Problem, Defect, Delay happened |
| **常见场景** | 延误已发生、缺陷已发现 |
| **易混淆概念** | Risk Register |
| **Example** | *The vendor is already two weeks late.* → Issue Log |

## 变更管理（Change）

### Change Request

| 字段 | 内容 |
|------|------|
| **English Term** | Change Request |
| **中文名称** | 变更请求 |
| **PMP考试含义** | 修改基准或已批准可交付成果的正式提议 |
| **关键词** | CR, CCB, Baseline, Impact Analysis |
| **常见场景** | First 题：变更类首选记录并评估 |
| **易混淆概念** | 直接执行变更；口头范围蔓延 |
| **Example** | *Client requests additional features.* → 先 Change Request |

### Perform Integrated Change Control

| 字段 | 内容 |
|------|------|
| **English Term** | Perform Integrated Change Control |
| **中文名称** | 实施整体变更控制 |
| **PMP考试含义** | 审查所有变更请求，批准并管理对基准的变更 |
| **关键词** | CCB, Approved, Update Plan |
| **常见场景** | 变更已提交后的审批与计划更新 |
| **易混淆概念** | Direct and Manage Project Work（执行已批准工作） |
| **Example** | *After CR approval, update the project management plan.* → Integrated Change Control |

## 相关方（Stakeholder）

### Manage Stakeholder Engagement

| 字段 | 内容 |

| **English Term** | Manage Stakeholder Engagement |
| **中文名称** | 管理相关方参与 |
| **PMP考试含义** | 沟通与协作以满足相关方需求、处理问题、促进参与 |

## 敏捷（Agile）

### Product Owner

| 字段 | 内容 |
|------|------|
| **English Term** | Product Owner |
| **中文名称** | 产品负责人 |
| **PMP考试含义** | 最大化产品价值；管理 Product Backlog 优先级 |
| **关键词** | Value, Priority, Backlog, Acceptance Criteria |
| **常见场景** | 需求优先级、是否纳入 Sprint |
| **易混淆概念** | Scrum Master；Project Manager |
| **Example** | *Who prioritizes features?* → Product Owner |

### Scrum Master

| 字段 | 内容 |
|------|------|
| **English Term** | Scrum Master |
| **中文名称** | Scrum Master |
| **PMP考试含义** | 促进 Scrum、移除障碍、教练团队 |
| **关键词** | Impediment, Facilitate, Coach, Servant Leader |
| **常见场景** | 团队障碍、流程促进 |
| **易混淆概念** | Product Owner；PM 分派任务 |
| **Example** | *The team is blocked by a tool issue.* → SM removes impediment |
